About me

I'm an experienced Software Engineer with 7 years of experience in the Game Industry . I currently reside in the sunny concrete jungle of Manila. 🇵🇭🌞

I primarily use the Unity Game Engine and C# in my day-to-day work and for hobby projects. I also do some backend work since I've mainly worked on live service mobile games, using languages like Go and Typescript / Javascript. I have the servers deployed in a neat little container using Docker and AWS . I also do a bit of web development using Node and Vue.

Despite primarily working on game projects, I'm also open to other software engineering roles. I'm always open to learning and working with different technologies. If you'd like to work together, please feel free to hit me up!
